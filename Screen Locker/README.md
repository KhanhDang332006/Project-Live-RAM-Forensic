# Screen Locker Demo

Thư mục chứa mã nguồn, công cụ và kịch bản demo điều tra **Screen Locker Ransomware** (mã độc khóa màn hình / vô hiệu hóa giao diện người dùng).

## Cấu trúc dự kiến
- `tools/`: Các script phân tích, phát hiện cơ chế khóa màn hình, registry startup, trích xuất mã mở khóa (nếu có).
- `samples/`: Mẫu thử nghiệm / proof-of-concept screen locker trong môi trường lab cô lập.
- `report/`: Báo cáo kết quả phân tích và điều tra.
