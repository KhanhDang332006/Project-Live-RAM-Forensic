# RaaS (Ransomware-as-a-Service) Demo

Thư mục chứa mã nguồn, công cụ và kịch bản demo điều tra **Ransomware-as-a-Service (RaaS)** (mô hình dịch vụ mã độc tống tiền, liên kết C2, phân tán payload và double extortion).

## Cấu trúc dự kiến
- `tools/`: Các script trích xuất config, phân tích mạng/traffic C2, điều tra luồng exfiltration.
- `samples/`: Mẫu cấu hình, log mạng giả lập (pcap), payload test.
- `report/`: Báo cáo kết quả phân tích và điều tra.
