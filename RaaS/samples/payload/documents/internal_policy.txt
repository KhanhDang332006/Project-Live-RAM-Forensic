NOVATECH SOLUTIONS
INTERNAL INFORMATION SECURITY POLICY
Document ID: SEC-POL-001
Classification: INTERNAL
Version: 1.2
Effective Date: 2026-09-01

1. PURPOSE

This document defines basic information security requirements
for employees and departments at NovaTech Solutions.

2. ACCESS CONTROL

- Employees must only access information required for their jobs.
- Shared accounts should not be used for business operations.
- Privileged accounts must be restricted to authorized personnel.
- Access permissions must be reviewed periodically.

3. PASSWORD AND AUTHENTICATION

- Employees must use strong, unique passwords.
- Multi-factor authentication should be enabled for important services.
- Passwords must not be stored in plain text.
- Suspected credential compromise must be reported immediately.

4. DATA PROTECTION

- Confidential documents must not be shared with unauthorized parties.
- Sensitive files must be stored in approved locations.
- Important data should be backed up regularly.
- Backup restoration procedures must be tested.

5. NETWORK SECURITY

- Unused network services should be disabled.
- Systems must receive security updates regularly.
- Network access should follow the principle of least privilege.
- Unusual outbound network traffic should be investigated.

6. INCIDENT RESPONSE

If a security incident occurs:

- Report the incident to the IT Security Department.
- Isolate affected systems when necessary.
- Preserve relevant logs and evidence.
- Do not delete suspicious files or logs before investigation.
- Restore affected systems only after the recovery process is approved.

7. RESPONSIBILITY

All employees are responsible for following this policy
and reporting suspected security incidents.

Approved by: IT Security Department
